# Sapiq Preview — GitHub Pages

Интерактивное демо Sapiq r39 для партнёров. Это НЕ торговый терминал с реальными ордерами.

## Два адреса после включения GitHub Pages

- **Публичный сайт:** `https://pilotbkv-dotcom.github.io/sapiq-demo/` (ожидаемый адрес, пока не опубликован)
- **Устанавливаемая PWA:** `https://pilotbkv-dotcom.github.io/sapiq-demo/pwa/#/ru/terminal/index.html` (ожидаемый адрес, пока не опубликован)

## Быстрая публикация

1. На https://github.com/new создайте **публичный** репозиторий `sapiq-demo` с веткой `main`. Не используйте репозиторий других проектов.
2. Распакуйте архив `Sapiq-r39-GitHub-Pages-two-links.zip`. В репозитории выберите **Add file → Upload files** и загрузите содержимое распакованной папки **в корень** (включая подкаталог `pwa/`). Сам ZIP-файл загружать нельзя — GitHub Pages не распаковывает его.
3. В `Settings → Pages` выберите `Build and deployment → Deploy from a branch → main → /(root)`, нажмите Save. Убедитесь, что сайт открывается по HTTPS.



### Важно для тестирования

- Сайт и PWA содержат ДЕМО-данные, не действуют на реальные ставки и кошельки.
- Тихие звуки кнопок включаются по действию пользователя.
- Демонстрация уведомлений — локальная имитация. **Закрытые Web Push НЕ работают без отдельного backend** и подключённого фида.
- GitHub Pages — статический хостинг; `server/` и секретов в пакете нет.
- На iPhone: Safari → Share → Add to Home Screen. Для Android: Chrome → Install app / Add to Home screen.
- PWA manifest, service worker и иконки хранятся в `/pwa/`, поэтому scope ограничен этой папкой.

### Безопасность

Публичный репозиторий и опубликованная страница доступны любому в интернете. **Не добавляйте реальный API-ключ, приватные ключи кошельков, токены прокси или реальные данные пользователей.**
